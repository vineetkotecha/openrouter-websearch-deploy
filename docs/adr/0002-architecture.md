# ADR 0002: architecture

Status: accepted, 2026-09-21

Use strict TypeScript on Node 22, Fastify, Zod, Postgres and pgvector. Ship a cloud-ready container backed by managed Neon Postgres; do not operate a local database. Keep adapters, contracts, MCP, evals and baseline mandate/ranking open under Apache-2.0. Learned weights, private outcome data and a hosted provider-quality map may remain hosted.
